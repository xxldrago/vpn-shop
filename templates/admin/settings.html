Настройки
Платежи, подключение к панели, тестовый доступ и оформление.
Подключение к Amnezia Panel
Токен выпускается в панели: Настройки → API-токены. Должен иметь права администратора (роль admin, которая выпустила токен).
Platega (онлайн-оплата)
Публичный URL используется для редиректа после оплаты и должен быть доступен Platega по HTTPS.
Платежи: тестовый режим Platega
Когда включено, оплата создаётся в тестовой среде с отдельными ключами и URL — реальные деньги не списываются. Вебхук принимает и тестовые, и боевые ключи.
Тестовая подписка
Выдаётся один раз каждому пользователю.
Реферальная программа
Бонусы начисляются на скидочный баланс пользователей и списываются при оплате подписки. Выключение программы не отменяет уже начисленные бонусы. Установите 0, чтобы отключить конкретный бонус/комиссию.
Telegram-бот
Получите токен у @BotFather. Для работы бота перезапустите его (команда python bot.py).
