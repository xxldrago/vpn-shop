# VPN Shop — надстройка для Amnezia Web Panel

Полноценная система продажи VPN-подписок, работающая поверх [Amnezia Web Panel](https://github.com/PRVTPRO/Amnezia-Web-Panel/). Приложение общается с панелью по её JSON API (Bearer-токены) и принимает онлайн-оплату через [Platega.io](https://docs.platega.io/).

## Возможности

- **Тарифные планы** — цена в рублях + количество дней доступа. Настраиваются в админке.
- **Промокоды** — % скидка или фиксированная сумма, лимит использований, срок действия. Настраиваются в админке.
- **Онлайн-оплата через Platega** — карты, СБП и другие методы. Вебхуки обрабатываются автоматически.
- **Тестовая подписка** — выдаётся один раз, длительность настраивается в админке (по умолчанию 3 дня).
- **Автовыдача конфигов** — после оплаты на **всех серверах панели** создаются подключения, конфиги доступны в личном кабинете (копировать / скачать .conf / vpn-ссылка / QR-код как в Amnezia Panel).
- **Личный кабинет пользователя** — статус подписки, конфигурации (в т.ч. QR-фрагменты и vpn-ключ), история заказов, редактирование профиля (email, Telegram, пароль).
- **Личный кошелёк (баланс)** — на баланс начисляются реферальные бонусы и комиссии, а также его можно **пополнить отдельно** через Platega. При покупке/продлении пользователь **сам выбирает способ оплаты**: полностью с баланса или картой через Platega (если на балансе 0 ₽ — сразу Platega). Баланс показывается в шапке, полный журнал операций — в кабинете.
- **Реферальная программа** — у каждого пользователя свой 8-символьный код и ссылка; бонус за первого клиента и % комиссии за повторные пополнения, всё настраивается/отключается в админке.
- **Техподдержка** — тикеты с чатом между пользователем и поддержкой.
- **Админ-панель** — статистика выручки, управление тарифами/промокодами/заказами, настройки Platega, подключения к панели и реферальной программы.
- **Роль поддержки** — отдельная страница тикетов для агентов.
- **Telegram-бот** — полноценный магазин прямо в Telegram: регистрация, покупка подписки, промокоды, активация тестовой, продление, баланс, тикеты, реферальная система. Работает на той же бизнес-логике, что и веб-магазин (`services.py`).

## Требования

- Python 3.10+
- Работающая Amnezia Web Panel (по умолчанию `http://127.0.0.1:5000`)
- Аккаунт Platega.io (ключи `X-MerchantId` и `X-Secret`)

## Установка

```bash
git clone <this-repo> vpn-shop
cd vpn-shop
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py                    # запуск на http://0.0.0.0:8080
```

Или через скрипт:

```bash
chmod +x run.sh && ./run.sh
```

## Настройка

1. Откройте `http://<host>:8080`, войдите под **admin/admin** (обязательно смените пароль).
2. В **Админ → Настройки** укажите:
   - URL панели (например `http://127.0.0.1:5000`)
   - API-токен панели — выпустите в Амнезии: **Настройки → API-токены** (роль админа)
   - `X-MerchantId` и `X-Secret` от Platega
   - Публичный URL магазина (HTTPS!)
3. Настройте **Callback URL** в личном кабинете Platega: `https://shop.example.com/webhook/callback`
4. Проверьте тарифы в **Админ → Тарифы**.

> ⚠️ Platega принимает вебхуки только на HTTPS с валидным сертификатом и публичным IP/доменом. Магазин нужно развернуть за обратным прокси (nginx + Let's Encrypt).

## Как это работает

```
Пользователь → выбирает тариф → вводит промокод → «Оплатить»
  → если на балансе есть средства — предлагается ВЫБОР способа оплаты:
     • «Оплатить с баланса» (списывается вся сумма, подписка активируется сразу)
     • «Оплатить картой (Platega)» (полная сумма картой, баланс не трогается)
     если баланс = 0 ₽ — сразу редирект в Platega
  → Platega присылает вебхук /webhook/callback
  → магазин: отмечает заказ оплаченным, создаёт пользователя и подключения
     на ВСЕХ серверах панели, выдаёт конфиги (при продлении срок добавляется)
  → /payment/success → личный кабинет с конфигурациями
```

## Telegram-бот

Полноценный магазин в Telegram (`bot.py`, `aiogram 3`). Запускается как отдельный процесс рядом с веб-приложением.

**Запуск:**
```bash
./run_bot.sh        # или: python bot.py
```

**Настройка:**
1. Создайте бота у [@BotFather](https://t.me/BotFather), получите токен.
2. Укажите токен: **Админ → Настройки → Telegram-бот** (поле «Токен бота»).
3. Перезапустите бота.

**Возможности бота:**
- `/start` — регистрация прямо в боте (логин + опционально реферальный код) или вход, если Telegram-ID уже привязан к ЛК.
- 🛒 Магазин / Тарифы — выбор тарифа, применение промокода, получение ссылки на оплату Platega.
- 📋 Мои подписки — активная подписка и история.
- 🔁 Продлить — повторная покупка тарифа.
- 🎁 Тестовый период — активация.
- 💰 Баланс — личный кошелёк, пополнение через Platega и история операций.
- 🎧 Тикеты — создание обращения и чат с поддержкой.
- 🔗 Реферальная система — свой код и ссылка.

> Если у пользователя уже есть ЛК в веб-магазине, достаточно указать в «Профиле» свой **Telegram ID** — бот автоматически подхватит аккаунт (логин по `telegram_id`).

Бот уведомляет об успешной оплате (вебхук Platega подтверждает заказ, фоновая задача бота отправляет сообщение).

## Реферальная система

- При регистрации каждому пользователю выдаётся уникальный 8-символьный код и ссылка вида `https://shop/register?ref=КОД`.
- Переход по ссылке сохраняет referrer в cookie на 30 дней; при регистрации нового пользователя по этой ссылке связь фиксируется.
- **Триггер:** первое пополнение реферала (реальное пополнение через Platega — оплата подписки картой или пополнение кошелька — от `threshold`, по умолчанию 100₽).
- **Действие:** рефералу начисляется бонус (`referral_bonus_referee`, 100₽), пригласившему — вознаграждение (`referral_bonus_referrer`, 100₽).
- **Пассивный доход:** при каждом последующем пополнении реферала пригласивший получает `referral_commission_percent`% (по умолчанию 25) от оплаченной суммы.
- Все начисления идут на **личный кошелёк** (журнал в кабинете → «Баланс»), который можно тратить на подписки или пополнять картой.
- Все параметры регулируются и отключаются в **Админ → Настройки → Реферальная программа** (выключение не отменяет уже начисленные бонусы).

## Структура

```
vpn-shop/
├── app.py                # FastAPI: роуты, платежи, вебхуки
├── services.py           # Общая бизнес-логика (веб + бот): заказы, подписки, рефералы, тикеты
├── bot.py                # Telegram-бот (aiogram 3) — магазин в Telegram
├── config.py             # Env-переменные и дефолтные настройки
├── database.py           # SQLite (планы, промокоды, заказы, тикеты, настройки)
├── auth.py               # Хеширование паролей (PBKDF2)
├── panel_client.py       # Обёртка над API Amnezia Web Panel
├── platega_client.py     # Обёртка над API Platega
├── templates/            # Jinja2: публичная часть, кабинет, админка
├── static/               # CSS (стекломорфизм)
├── run.sh                # Запуск веб-магазина
├── run_bot.sh            # Запуск Telegram-бота
└── mock_panel.py         # Заглушка панели для локальных тестов (dev)
```

## Безопасность

- Смените `SHOP_SECRET_KEY` в окружении (подпись сессий).
- IP-токен панели храните только в настройках магазина.
- По умолчанию создаётся администратор `admin/admin` — смените пароль сразу после входа.
